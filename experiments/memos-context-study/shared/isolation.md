# Execution isolation requirements

The scaffold creates separate application file copies, independent Git directories and no project remotes. It refuses to reset edited projects. These are preparation safeguards, not an operating-system sandbox or a coding-agent launcher.

Before scored execution, the execution layer must enforce:

1. Agent access only to its designated project and permitted tools/materials; no parent research folders, sibling methods, source cache, hidden evaluator or other run outputs.
2. Fresh conversations and separate writable home, caches, memory, dependencies, temporary storage and application/database state. Do not share a writable Memos data directory or database between methods.
3. A common, recorded tool/network policy and budget. Reading research conclusions or public reference solutions must not become accidental task context.
4. Immutable public/hidden evaluation inputs as appropriate; end the agent session and seal final artifacts before independent hidden evaluation.
5. Evidence of boundary enforcement and attempted-access checks, not merely different folder names.

No agent execution command is implemented. The third method remains a disabled shell. Models, task inputs, budgets and evaluation checks must be selected and frozen before a real comparison can run.
