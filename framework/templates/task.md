# Task record template

Status: unfilled planning aid, not a selected task.

## Identity and provenance

Record task ID, selection rationale, project commit, task-input hash, dependencies and environment reference. Note public-solution or contamination concerns.

## Agent-visible requirements

Describe requested behavior, constraints and observable criteria. Identify permitted materials. Exclude hidden tests and reference solutions.

## Evaluator-only record (store separately)

Link frozen acceptance/regression checks, evaluator hash, clean-start results, reference-validation evidence if available, review rubric and feedback policy. Record coverage limits. Never copy this section into agent context.

## Pairing and execution

Record common starting state, pairing group, method configuration/context hashes, prompt hash, isolation evidence and resource-record links. Separate completion, timeout and infrastructure status from correctness; record deviations.
