# Maintenance-observation template

Status: unfilled aid, not evidence of an observed maintenance episode.

## Shared change and workflow state

Record episode ID, before/after source commits, change scope, workflow ID and its own prior context hash. Link shared audit scope and source evidence. Do not import another method's context or conclusions.

## Accuracy and consistency

For each inspected claim, record location, source/test evidence, classification (supported, stale, contradictory, unsupported or unresolved), detection time and reviewer. Report inspected/affected claim denominators. Distinguish a source disagreement from demonstrated falsehood.

## Repair and verification

Record edits/removals, resulting context hash, commands/review and observed outcomes. Note whether updates were requested, automatic or manually discovered. Measure detection/repair latency only with recorded timestamps. Link update/review/revalidation resources. Record unresolved defects and observation limits.
